# Thoughts

Architecturally I think things are in a stable spot and can be a vehical for powerful expression. However, I've reached an impass where my knowledge of TouchDesigner needs to increase in order to execute that expressiveness. 

Iter4 is like a "Hello, World" for distinct types of image reactivity given a single audio input split into `n` distinct analyses types (`n=4` in this case). And the semantic significance of these distinct types of reactivity are that different spatial areas "remember" or "react" distinctly. A powerful idea. The execution, however, is a bit pedestrian. 

The framework is strong.

- Ask a question
- create a semantic mapping for the language of "the answer"
- implement the answer via that semantic mapping 

Consequently, the "meaning" layer is preserved and the result SHOULD feel more profound than a parlour trick. Also, that framework transcends implentation. The tooling of the implementation becomes subserviant to the creative process - which is the point. 

But in order to have an expressive implementation, there comes a time where facility with the tooling is necessary to acquire. 

> This is my current state.
